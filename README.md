# Smart HR & Employee Management System

## Description

A web application for managing employee records, attendance, leave requests, departments, and payroll. It provides role-based dashboards for Admin, HR, and Employees, along with notifications and workforce reports.

## Tech Stack

- **Backend:** Python 3.11+, Django, Django REST Framework
- **Database:** PostgreSQL
- **ORM:** Django ORM
- **Frontend:** HTML, CSS, JavaScript, Chart.js
- **Email:** SMTP or Transactional Provider
- **Testing:** pytest / Django TestCase
- **Version Control:** Git / GitHub
- **Optional:** Celery, Redis, Docker

## Requirements

- [ ] User authentication, roles, and permissions
- [ ] Employee profiles and employment records
- [ ] Department and job title management
- [ ] Attendance tracking and monthly summaries
- [ ] Leave applications, approvals, and status tracking
- [ ] Salary components, payroll records, and payslips
- [ ] Email notifications
- [ ] Downloadable workforce reports
- [ ] Audit logs and access control for sensitive information
- [ ] Synthetic demo employee data
